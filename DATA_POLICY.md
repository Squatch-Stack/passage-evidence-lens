# Data and attribution policy

| Item | Included in this repository | Source and status |
| --- | --- | --- |
| Interface HTML, CSS, JavaScript and loopback adapter | Yes | Original Squatch Stack code; MIT license |
| Four canonical verse labels and links | Yes | Navigation pointers to the [official manuscript viewer](https://codexsinaiticus.org/en/) |
| CSS folio illustration | Yes | Original abstract artwork; not a facsimile |
| Official XML transcription and corrections | No | [Codex Sinaiticus Project](https://codexsinaiticus.org/en/project/transcription_download.aspx), CC BY-NC-SA 3.0; only available through an explicitly configured local research adapter |
| Manuscript images, raking-light views, translations, and protected metadata | No | [Institutional copyright terms](https://codexsinaiticus.org/en/copyright.aspx) apply separately |
| Legacy site application code and visual assets | No | No public source-code license for the running site was established |

The public demo must remain source-link-only until each imported asset has an explicit storage, display, redistribution, sponsorship, and attribution decision. Any approved XML derivative must retain the project's attribution and applicable share-alike terms. A sponsorship button for independent code does not grant rights to the underlying manuscript media.
