# Funding independent open interface work

The code and public demo are free. Support is voluntary and does not change source access, textual conclusions, or review priority from the manuscript institutions.

- [GitHub Sponsors](https://github.com/sponsors/Squatch-Stack): recurring or one-time support for Squatch Stack's open-source portfolio.
- [Ko-fi](https://ko-fi.com/squatchstack): one-time support for the same independent work.

Contributions go to **Squatch Stack**, not to the British Library, Leipzig University Library, St Catherine's Monastery, the National Library of Russia, or the Codex Sinaiticus Project. These channels are not an institutional fundraising campaign. The existing sponsor pages describe Squatch Stack's wider open work; a gift through them is not automatically earmarked for this prototype.

For this project, useful funded work would be accessible user testing, source-linked correction UX, a rights-aware IIIF/Web Annotation adapter and long-term maintenance. We will publish the corresponding issues, code and test results openly. Sponsors cannot buy a preferred historical interpretation, access to restricted media, or endorsement by an institution.

Patreon is not yet linked here because its current page URL could not be independently verified from our testing environment. It can be added once confirmed, with the same attribution and rights boundaries.
